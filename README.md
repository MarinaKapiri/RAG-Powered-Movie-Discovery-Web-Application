# RAG-Powered Movie Discovery Web Application

🔗 **Live Demo:** https://rag-movie-app.lemonwater-03b92927.northeurope.azurecontainerapps.io

A full-stack movie discovery application featuring traditional search, semantic vector search, AI recommendations, and RAG-based recommendations.

**Tech stack:** React, FastAPI, PostgreSQL + pgvector, OpenAI, OpenRouter, Docker, Microsoft Azure.
